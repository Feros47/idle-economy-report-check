# Original hypothetical fixtures

These two scenarios are the original Cozy Garden example and its one-value change: seed-bed `costGrowth` is 1.16 in `baseline.json` and 1.20 in `candidate-cost-growth.json`.

The report fixtures retain the `scenario`, `summary` and `milestones` fields from the actual browser exports verified on 12 October 2026. Trace, chart points and final generator rows were omitted because the checker does not use them. Numeric results were not edited. The browser reports have no root `schemaVersion`; the selected scenario has `version: 1`.

Baseline produces 1,000 coins at 293.8247111111111 seconds; candidate at 312 seconds. Candidate final production is 603729.4053121014 with 74 purchases. The deadline is an explicit tutorial choice, not a recommendation for a real game. Starting coins are excluded from production milestones.
